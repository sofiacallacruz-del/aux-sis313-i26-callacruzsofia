PRÁCTICA 5 - JAVASCRIPT

Preguntas Teóricas

1) Formas de conectar HTML con JavaScript

Existen dos formas principales de conectar JavaScript con HTML:

a) JavaScript Interno

Se escribe el código JavaScript dentro de la etiqueta <script> en el mismo archivo HTML. 

<script>
    alert("Hola Mundo");
</script>

b) JavaScript Externo

Se escribe el código JavaScript en un archivo separado con extensión .js y luego se enlaza al HTML. 

<script src="script.js"></script>

Actualmente se recomienda utilizar JavaScript externo porque permite organizar mejor el código, reutilizar archivos y facilitar el mantenimiento.

2) ¿Cómo visualizar resultados en la consola?

Paso 1: Abrir el navegador.

Paso 2: Presionar F12 o clic derecho → Inspeccionar.

Paso 3: Abrir la pestaña “Console”.

Paso 4: Utilizar console.log() para mostrar resultados. 

console.log("Hola desde JavaScript");

La consola permite visualizar mensajes, resultados de operaciones y errores del programa.

3) Variables en JavaScript

Las variables permiten almacenar información.

var

var nombre = "Juan";

Tiene alcance global o de función. Actualmente no se recomienda mucho porque puede causar errores.

let

let edad = 20;

Permite modificar el valor y tiene alcance por bloque.

const

const pi = 3.1416;

No permite cambiar el valor después de declararlo.

Actualmente se recomienda usar let y const porque son más seguras y organizadas.
